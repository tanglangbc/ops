# 交易工作台与研究呈现层分离

**Status**: accepted（2026-10-22 · 本轮需求讨论）

币安量化系统采用独立的本机交易工作台，不把既有只读研究站点改造成交易终端。前端采用 React + Vite + ECharts，Python 后台独立负责公开行情采集、回测、策略模拟执行与风险控制，SQLite 保存业务状态；后台不依赖浏览器持续打开。首版只调用币安公开行情接口，不使用私有交易 API 密钥，不查询账户、不提交真实订单，工作台仅允许本机访问。选择这一边界是为了复用现有研究代码与前端技术，同时保护已验收的只读研究呈现层；后续若要访问真实账户或交易，必须作为独立决策重新设计权限、安全和验收，不可因为预留接口而默认启用。

## Consequences

- 研究站点继续按现有 ADR-0001 运行：构建期烘焙、只读、离线可开；交易工作台另有运行时数据链。
- 关闭浏览器不应停止后台模拟引擎；但服务或系统重启后，策略默认暂停，完成恢复前检查并由用户明确确认后才可恢复。
- 首版不配置、不存储私有 API 密钥；不能展示真实账户余额、真实持仓或真实成交。
- 策略、回测与每次模拟运行批次均需记录可复现的版本与参数；模拟账户重置以创建新批次实现，不能覆盖历史记录。
- 本机服务边界应通过绑定回环地址与本地访问限制落实，不开放局域网或公网访问。
