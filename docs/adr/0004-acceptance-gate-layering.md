# 验收门的分层与冻结纪律

**Status**: accepted（2026-10-22 · 本轮需求讨论 · Round 1 Q2 + 调研回填）

首版同时存在**三套**验收门，且都指向同一条策略的历史结果：① 2026-10-17 已冻结的 `binance-spot-quant/reports/FREEZE_4H_RULE.md`（成本公式 `fee 0.1%×2 + slippage 0.1%×2 = 0.4%`；判据 `trades≥30` / `segmentsWithTrades≥15` / `netAfterCosts>0` / `vsNull`（随机入场 p95）/ `holdout=XRPUSDT`；并明文承诺「**从此不因结果不好而事后改门槛**」）；② `SYSTEM_ROADMAP.md` 的 M1 门（任一新策略须给出 DSR 概率 + OOS 超额 + 四档成本净收益）；③ 本轮 ADR-0003 新提的「≥5 个滚动样本外窗口 + 扣除成本后正期望 + 95% 置信区间下界高于零 + 多重比较修正 + 1.5× 成本压力」。而 4h 策略**已按 ① 判 NOT APPROVED**，`realMoney` 处于 `LOCKED`。

**决定：新门只对**新**策略版本 / 新候选生效；① 与已有历史结论按原口径**继续有效、不被改写**。新增的口径另开一条冻结记录（写明时间与理由），与本 ADR 一并生效。新门本身是**两条并列的门，不是一条复合布尔值**：

- **窗口级门** —— 对该策略版本在 W 个滚动样本外窗口上的**逐窗口净收益**（扣全部成本）做区间估计，取 95% **下界 > 0**。它回答「净收益是否为正且稳健」。
- **选择偏差门** —— 沿用既有实现（`research/stats.py` 的 `DSR ≥ 0.95 AND PBO ≤ 0.5 AND reality_p ≤ 0.05`）。它回答「N 次尝试下的最优是不是运气」。

**两条硬约束**（均为本轮调研结论，理由见下）：

1. **W（窗口数）不进 α 的分母。** W 个窗口是**同一个假设的 W 次实现**，不是 W 次比较；只有当搜索过**窗口长度或起点**时，W 才计入 N。
2. **「≥5 个窗口」如实标注为项目自定口径。** DSR / PBO-CSCV / White Reality Check / Hansen SPA 四套框架均以**期间数**或**模型数**为参数，**不以窗口数为参数**，文献里没有「5」这个数。W ≥ 10（自由度 ≥ 9）更稳；W = 5 只作最低可接受下限，且必须预先声明其下界对区间估计方法敏感。

## Considered Options

- **新门取代旧冻结件**：否。撤回一次已生效的冻结，等于把「预注册」降级为「事后可调」——本仓三条策略线阵亡的根本原因正是这个（`SYSTEM_ROADMAP.md` §1 判断：L2 研究纪律是最弱的一环）。
- **两套并列但压成一个布尔值**：否。既有 t 统计量的单位是**bar**（`research/edge_scan.py:234`，样本量 = bar 数，量级 1000+），而窗口级门的单位是 **window**（W=5 ⇒ **4 自由度**）。把严格 Bonferroni（当前 N=68 ⇒ α ≈ 7.35e-4）与 4 自由度的窗口级检验压成单门，**几乎不可能通过**，等于把门做成不可达。
- **只加窗口级门、放松既有三件**：否。那正是「用新门替换旧门」，与 ① 的承诺直接冲突。

## Consequences

- 新门必须落成**可执行、可退非零码**的检查（照本仓既有 `EXIT_CODES` 的模式），而不是写在报告正文里的形容词；「**哪一层没过**」必须可诊断，不接受一个复合布尔值掩盖。
- 新门的输入是**逐窗口净收益序列**，而既有 `pbo_cscv` 的输入是「多配置 × 时间轴」矩阵、`deflated_sharpe_ratio` 的输入是单条曲线的 Sharpe 与偏度峰度——**三者互补，不可互相替代**，实现时不要拿任何一个去顶另一个。
- 「1.5× 成本压力」是**新档位 + 新判据**，不是已有开关：跑成本档的机制已在（`backtest-4h.json` 有手续费×2 / 单边滑点 0.25% / 0.50% 三档），但代码里出现的 `1.5` 是**集中度比率**（`research/edge_scan.py:385-387`），与成本无关。基准成本假设**必须先冻结**再谈倍数。
- 样本不足时判「**证据不足**」，不得降门槛——这条同时约束工程门与盈利门（见 GLOSSARY「工程验收门 / 盈利验收门」）。
