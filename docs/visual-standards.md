# 可视化视觉约定（VS-01 的落地约定）

> 来源：票 [#7 三档标注与 carry 双数的视觉原型](https://github.com/tanglangbc/ops/issues/7) 的两个原型
> （`viz/prototype/`，已移到分支 `prototype/vs01-labeling`）+ 规范 `research/VS_01_可视化规范.md`。
> 本文是**已裁决的约定**，不是待议清单；实现见 [#3](https://github.com/tanglangbc/ops/issues/3)。

## 1. 页面结构（拍板：B 的图例 + A 的密度）

- **每对象一页**（`ADR-0001`），页内是**卡片流**：一对象一张卡，卡内可有多图。
- **档位图例常驻**在页面左侧或顶部（取自原型变体 B）——三档不能靠读者记忆颜色。
- **档位区分不依赖颜色**（色盲 + 黑白打印可用）：
  - 已发生事实：实线条 + 正常底色；
  - 数据推断：**斜纹底** + 「推断」角标 + 虚线；
  - 交易假设：**灰显 + 点线边框** + 「未验证」标签。
- 鼠标悬停（或键盘聚焦）任意数字 → tooltip 给出**档位 + 来源文件:行号 + 口径**。
- 原型变体 C（表格 + 行内 sparkline）**保留为「可打印/导出」形态**，不作主界面。

## 2. 视觉 token（唯一真源，站点直接移植这一段）

```css
:root{
  --tier-fact:#1f6feb;        /* 已发生事实：正常色 */
  --tier-inferred:#b26a00;    /* 数据推断：加「推断」角标 + 斜纹 */
  --tier-hypothesis:#6e7781;  /* 交易假设：灰显 + 「未验证」 */
  --tier-gap:#57606a;         /* 核不到：灰块，不留空白 */
  --stale:#b91c1c;            /* 页面级陈旧（36h，见 #9） */
}
```

## 3. carry 双数（红线）

`runbook 3.6%/年`（回放层，档位＝数据推断）与 `近 30 天实测 1.8–2.1%/年`（档位＝已发生事实）
**必须同格同画**，各自带窗口与口径；只画前者即违规（VS-01 §3）。

## 4. 缺口与陈旧是两种东西，不许合并

- **图级缺口**：`核不到` 灰块（斜纹），写明缺什么、缺多少、为什么不连线；**不留白**。
- **页面级陈旧**：整页顶部红条，阈值 36 小时（`manifest.coverage.end` 与最近成功构建任一超限），
  连续 3 天升级为「严重陈旧」；不引入外部告警（见 [#9](https://github.com/tanglangbc/ops/issues/9)）。

## 5. 状态词表（封闭）

`通过` / `不通过` / `证据不足`。原型里出现的第四种「不适用（非回测件）」**待用户裁**——
在裁决前，站点一律只用上述三态；非回测件用「证据不足」或干脆不出状态徽标。

## 6. 每图必备元数据条（VS-01 §5，缺一即作废）

来源（文件+行号 或 sha256 前 16）｜实验编号（`EXPERIMENT_INDEX.md`）｜口径（含费率/滑点/折算）｜
生成时刻｜数据截止时刻｜档位。六个都在同一条上，缺任何一项该图作废。

## 7. 原型产物怎么处理

- 胜出的结构（本文 §1）落进这里的约定与站点实现；
- 三个变体原件与切换条属**一次性产物**，留在分支 `prototype/vs01-labeling`，不进 `master`；
- 另一会话产出的「视觉约定样张」同属原型证据，一并留在该分支。
