# Release Checklist

## Identity
- [ ] SKU name matches directory and SKILL.md name
- [ ] version set
- [ ] license set
- [ ] compatibility statement verified

## Package
- [ ] SKILL.md present
- [ ] README.md present
- [ ] no secrets
- [ ] no private data
- [ ] no blocked file types
- [ ] no hidden files except allowed `.gitignore`
- [ ] no symlinks
- [ ] directory depth compliant
- [ ] total package size compliant
- [ ] SKILL.md under 500 lines

## Function
- [ ] 3+ test cases pass
- [ ] clean install test passes
- [ ] failure handling tested
- [ ] README matches actual behavior

## Marketplace
- [ ] current official docs checked
- [ ] duplicate research completed
- [ ] price selected as a test hypothesis
- [ ] category/tags selected
- [ ] short description ≤ current marketplace limit
- [ ] `skillhq validate` passed

## Publication gate
- [ ] user explicitly approved publication
- [ ] exact publish command re-verified today
- [ ] publish command displayed in final report
- [ ] publication executed manually/under user control

## Post-release
- [ ] listing URL recorded
- [ ] version recorded
- [ ] changelog recorded
- [ ] buyer feedback process created
